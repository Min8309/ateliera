# 🖌️ Ateliera (아틀리에라)
> **"Trace to Space (붓질의 궤적이 머무는 가상 갤러리)"**  
> 창밖으로 한강과 서울 스카이라인이 보이는 작업실에서 수채화 느낌으로 창작한 뒤, 3D 액자를 결합해 완성하고 타임랩스로 궤적을 되짚어보는 Three.js 기반 인터랙티브 디지털 페인팅 플랫폼입니다.

---

## ✨ 핵심 아키텍처 및 주요 기능

### 1. 듀얼 캔버스 렌더 파이프라인 (Dual-Layer Canvas Architecture)
- **Paper Canvas (선택한 해상도)**: 종이 결을 한 번 생성해 보존하는 바탕입니다. 지우개로 그림을 지워도 종이는 유지됩니다.
- **Background Canvas (선택한 해상도)**: 완료된 획이 누적되는 투명 레이어입니다.
- **Active Canvas (선택한 해상도)**: 실시간 1개의 획만 그리는 임시 레이어입니다.
- **저지연 연산 (`desynchronized: true`)**: 지원 브라우저에서 저지연 캔버스 옵션을 요청합니다. 실제 입력 지연은 기기와 브라우저에 따라 달라집니다.
- **CanvasTexture 바인딩**: Three.js의 Plane Quad Mesh(`PlaneGeometry(2, 2)`)에 텍스처를 실시간 동기화합니다. 프레임 속도는 기기 성능과 화면 해상도에 따라 달라집니다.

### 2. 고정밀 저지연 입력 수집 & 실시간 HUD
- **`e.getCoalescedEvents()` 대응**: 초고속 붓질 시 브라우저 이벤트 큐에 뭉쳐진 미세 좌표를 처리합니다. API가 없거나 빈 배열을 반환하면 원래 포인터 이벤트를 사용합니다.
- **하이브리드 필압 정규화**: 스타일러스 펜(Apple Pencil, Wacom)의 물리 필압(`e.pressure`)과 마우스 이동 속도 기반 가상 필압을 지원합니다.
- **실시간 디버그 HUD**: FPS, 1프레임 렌더 타임(ms), 입력 이벤트 처리 시간(ms), 누적 스트로크/포인트 수를 실시간으로 표출합니다.

### 3. 중간점 기반 2차 베지어 곡선 보간 (Midpoint Quadratic Bézier)
- 연속된 원시 포인트를 제어점으로 하는 2차 베지어 곡선 $B(t) = (1-t)^2 M_0 + 2(1-t)t P_1 + t^2 M_1$을 실시간 생성합니다.
- 브러시별 고유 Spacing 비율로 균일하게 스탬핑하여, 획을 부드럽게 연결하며 마지막 입력 좌표까지 렌더링합니다.

### 4. 브러시 5종 + 지우개
- **🖊️ 기본 펜 (Pen)**: 경계가 또렷하고 매끄러운 잉크 펜. 필압에 따른 선형 굵기 비례(`size = baseSize * pressure`), 불투명도 100%.
- **✏️ 연필**: 가는 흑연 선, 필압에 따른 농도, 종이 좌표에 고정된 미세 결.
- **▧ 목탄**: 넓고 거친 입자, 가벼운 가루 테두리와 기울기에 반응하는 눕힌 팁.
- **🎨 물감**: 불투명한 안료와 밝고 어두운 붓결로 두께감을 표현하는 2D 브러시. 실제 3D 높이는 별도의 3D 입체 브러시를 사용합니다.
- **🖌️ 수채화 (Watercolor)**: 중심부는 맑고 외곽 링에 안료가 맺히는 **Water Edge 림 텍스처**와 반투명 알파 겹침(Glazing), 지수 감쇄 미세 안료 번짐.
- **💨 에어브러시 (Airbrush)**: 2D 가우시안 래디얼 팁과 0.06 초밀도 스탬핑으로 밴딩(얼룩) 없는 극도의 매끄러운 그라데이션 스프레이.
- **◈ 3D 입체 (Volume)**: 포인터 경로를 실제 Three.js 튜브 메시로 만듭니다. 필압에 따라 굵기가 변하고 양 끝은 구체로 마감됩니다. `돌출` 슬라이더로 캔버스 앞쪽 높이를 조절하며 우클릭 회전으로 옆면을 확인할 수 있습니다. 네온 색상은 발광 재질과 부드러운 광륜이 더해집니다. 실시간 메시 갱신은 프레임당 한 번으로 제한하고 긴 획은 최대 약 256개 제어점으로 줄입니다.
- **🧹 지우개 (Eraser)**: 활성 레이어에 지우개 마스크를 만들고 `destination-out`으로 그림 레이어에 적용합니다. 드래그 중 미리보기와 완료 후 결과가 일치하며, 지우개 궤적도 데이터로 보존됩니다. 3D 획은 닿은 획 전체를 숨기며 Undo로 복원할 수 있습니다. 지우개 이후에 새로 그린 3D 획은 유지됩니다.

### 5. 안료 14종 + 형광·네온 6종 팔레트
- 한국화 및 서양 수채화 대표 14종 안료와 형광 옐로 라임·네온 그린·시안·핑크·바이올렛·형광 오렌지 6종, 커스텀 컬러 피커.
- 형광/네온 RGB 색상은 모든 브러시에서 선택할 수 있습니다. 3D 입체 브러시에서는 네온 팔레트 선택 시 발광 효과도 적용됩니다.

### 6. 한강변 서울 작업실 & 작품 완성 시퀀스
- **서울 전망**: 통창 너머 한강, 교량, 산 능선, N서울타워·롯데월드타워를 단순화한 스카이라인을 자체 제작 파노라마로 표현합니다. 실제 위치를 그대로 재현한 지리 모델은 아닙니다.
- **낮 / 밤**: 왼쪽 작업실 패널에서 전환합니다. 낮에는 햇살과 밝은 강물이, 밤에는 달·도시의 창문 불빛·교량 조명·강물 반사와 따뜻한 실내등이 나타납니다.
- **작업실 가구**: 원목 바닥, 이젤, 창가 작업 테이블, 붓과 물감 병, 책장, 벤치, 화분, 펜던트 조명.
- **캔버스 크기**: 정사각형 2048×2048, 가로형 2560×1440, 세로형 1440×2560, 작은 정사각형 1024×1024. 크기 변경 시 그림과 Undo/Redo 데이터를 같은 배율로 중앙에 맞춥니다. 비율이 다른 크기로 여러 번 바꾸면 그림이 더 작아질 수 있습니다. 새 비율의 가장자리까지 늘이거나 잘라내지는 않습니다.
- **크기 연동**: 3D 캔버스·액자·서명 위치·PNG 및 JSON 해상도가 선택한 크기를 따릅니다. 크기 변경 시 기존 액자는 제거되며 다시 완성하기로 부착할 수 있습니다.
- **완성하기 시퀀스 (Finish Artwork)**:
  1. 카메라 정면 줌인 및 조작 잠금.
  2. 작품 제목 및 작가 서명 입력.
  3. 캔버스 우측 하단 서명 각인 및 3D 몰딩 액자(우드/골드/블랙) 스냅 장착.
  4. 고해상도 DataURL 이미지 및 `strokesData` JSON 패키징, `localStorage` 영구 보관.

### 7. 타임랩스 리플레이 & PNG/JSON 데이터 추출
- 2D와 3D 획 모두 Undo/Redo, 초기화, 크기 변경과 타임랩스에 연결되어 있습니다. JSON에는 `tool: "volume"`, `neon`, `depth`와 경로·필압을 저장합니다. PNG는 입체 획을 정면에서 렌더링한 이미지로, 선택한 캔버스 해상도를 유지합니다. 입체 기하 정보 자체는 PNG에 포함되지 않습니다.
- 누적된 스트로크 데이터를 기반으로 첫 획부터 현재까지 실제로 붓질하듯 `requestAnimationFrame`으로 캔버스에 재현합니다.
- 데이터 추출 버튼 클릭 시 규격화된 Artwork JSON(`{ id, width, height, strokes, createdAt }`) 파일 자동 다운로드.

## 🛠️ 기술 스택

- **Core**: JavaScript (ES6+ Modules), Three.js (ESM), 데스크톱/터치 포인터 입력 (WebXR 연결은 향후 구현)
- **Controls**: Three.js OrbitControls (우클릭 회전 / 휠 줌 / 좌클릭 드로잉 격리)
- **Canvas Pipeline**: HTML5 Dual Canvas (Offscreen), CanvasTexture
- **Styling**: Vanilla CSS3, 글래스모피즘 (Glassmorphism), Noto Sans KR / Outfit
- **Build & Dev Tool**: Vite 6

## 🚀 빠른 시작 (Getting Started)

### 의존성 설치
```bash
npm ci
```

### 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 [http://localhost:3000/](http://localhost:3000/)으로 접속합니다.

### 회귀 테스트
```bash
npm test
```
Node.js 내장 테스트 러너로 획의 시작/끝과 재생 경로 일치, 브러시 상태 복원, 완성작 데이터 스냅샷, 액자 리소스 해제를 검사합니다. 실제 WebGL 렌더링과 포인터 조작은 브라우저에서 별도로 확인해야 합니다.

### 프로덕션 빌드
```bash
npm run build
```

## 개발 상태 및 제한

현재 실행 진입점은 `src/main.js`이며, 연결되지 않았던 초기 씬·입력·WebXR·히스토리 구현은 제거했습니다. WebXR/VR 진입 버튼과 컨트롤러 드로잉은 아직 지원하지 않습니다.

작품 저장은 브라우저 `localStorage`를 사용합니다. 이미지와 획 데이터가 저장 용량을 초과하면 영구 저장이 실패할 수 있으므로 중요한 작품은 PNG/JSON으로 다운로드하세요. 서버 저장과 가져오기 기능은 향후 개발 대상입니다.
