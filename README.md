# 🖌️ Ateliera (아틀리에라)
> **"Trace to Space (붓질의 궤적이 머무는 가상 갤러리)"**  
> 창밖으로 한강과 서울 스카이라인이 보이는 작업실에서 수채화 느낌으로 창작한 뒤, 3D 액자를 결합해 완성하고 타임랩스로 궤적을 되짚어보는 Three.js 기반 인터랙티브 디지털 페인팅 플랫폼입니다.

## ✨ 핵심 아키텍처 및 주요 기능

### 1. 듀얼 캔버스 렌더 파이프라인 (Dual-Layer Canvas Architecture)
- **Paper Canvas (선택한 해상도)**: 종이 결을 한 번 생성해 보존하는 바탕입니다. 지우개로 그림을 지워도 종이는 유지됩니다.
- **Background Canvas (선택한 해상도)**: 완료된 획이 누적되는 투명 레이어입니다.
- **Active Canvas (선택한 해상도)**: 실시간 1개의 획만 그리는 임시 레이어입니다.
- **저지연 연산 (`desynchronized: true`)**: 지원 브라우저에서 저지연 캔버스 옵션을 요청합니다. 실제 입력 지연은 기기와 브라우저에 따라 달라집니다.
- **CanvasTexture 바인딩**: Three.js의 Plane Quad Mesh(`PlaneGeometry(2, 2)`)에 텍스처를 실시간 동기화합니다. 프레임 속도는 기기 성능과 화면 해상도에 따라 달라집니다.

### 2. 고정밀 저지연 입력 수집 & 실시간 HUD
- **`e.getCoalescedEvents()` 대응**: 초고속 붓질 시 브라우저 이벤트 큐에 뭉쳐진 미세 좌표를 처리합니다. API가 없거나 빈 배열을 반환하면 원래 포인터 이벤트를 사용합니다.
- **하이브리드 필압 정규화**: 스타일러스 펜(Apple Pencil, Wacom)의 물리 필압(`e.pressure`)과 마우스 이동 속도 기반 가상 필압을 지원합니다.
- **실시간 디버그 HUD**: FPS, 1프레임 렌더 타임(ms), 입력 이벤트 처리 시간(ms), 누적 스트로크/포인트 수를 실시간으로 표출합니다.

### 3. 중간점 기반 2차 베지어 곡선 보간 (Midpoint Quadratic Bézier)
- 연속된 원시 포인트를 제어점으로 하는 2차 베지어 곡선 $B(t) = (1-t)^2 M_0 + 2(1-t)t P_1 + t^2 M_1$을 실시간 생성합니다.
- 브러시별 고유 Spacing 비율로 균일하게 스탬핑하여, 획을 부드럽게 연결하며 마지막 입력 좌표까지 렌더링합니다.

### 4. 브러시 5종 + 지우개
- **🖊️ 기본 펜 (Pen)**: 경계가 또렷하고 매끄러운 잉크 펜. 필압에 따른 선형 굵기 비례(`size = baseSize * pressure`), 불투명도 100%.
- **✏️ 연필**: 가는 흑연 선, 필압에 따른 농도, 종이 좌표에 고정된 미세 결.
- **▧ 목탄**: 넓고 거친 입자, 가벼운 가루 테두리와 기울기에 반응하는 눕힌 팁.
- **🎨 물감**: 불투명한 안료와 밝고 어두운 붓결로 두께감을 표현하는 2D 브러시. 실제 3D 높이는 별도의 3D 입체 브러시를 사용합니다.
- **🖌️ 수채화 (Watercolor)**: 중심부는 맑고 외곽 링에 안료가 맺히는 **Water Edge 림 텍스처**와 반투명 알파 겹침(Glazing), 지수 감쇄 미세 안료 번짐.
- **💨 에어브러시 (Airbrush)**: 중심부터 가장자리까지 연속적으로 옅어지는 분사 구름과 미세 물감 입자. 높은 농담 설정에서도 단단한 원형 자국이 생기지 않도록 분사량을 제한하며, 필압에 따라 색이 쌓입니다.
- **◈ 3D 입체 (Volume)**: 포인터 경로를 실제 Three.js 튜브 메시로 만듭니다. 필압에 따라 굵기가 변하고 양 끝은 구체로 마감됩니다. `돌출` 슬라이더로 캔버스 앞쪽 높이를 조절하며 우클릭 회전으로 옆면을 확인할 수 있습니다. 네온 색상은 발광 재질과 부드러운 광륜이 더해집니다. 실시간 메시 갱신은 프레임당 한 번으로 제한하고 긴 획은 최대 약 256개 제어점으로 줄입니다.
- **🧹 지우개 (Eraser)**: 활성 레이어에 지우개 마스크를 만들고 `destination-out`으로 그림 레이어에 적용합니다. 드래그 중 미리보기와 완료 후 결과가 일치하며, 지우개 궤적도 데이터로 보존됩니다. 3D 획은 닿은 획 전체를 숨기며 Undo로 복원할 수 있습니다. 지우개 이후에 새로 그린 3D 획은 유지됩니다.

### 5. 안료 14종 + 형광·네온 6종 팔레트
- 한국화 및 서양 수채화 대표 14종 안료와 형광 옐로 라임·네온 그린·시안·핑크·바이올렛·형광 오렌지 6종, 커스텀 컬러 피커.
- 형광/네온 RGB 색상은 모든 브러시에서 선택할 수 있습니다. 3D 입체 브러시에서는 네온 팔레트 선택 시 발광 효과도 적용됩니다.

### 6. 한강변 서울 작업실 & 작품 완성 시퀀스
- **서울 전망**: 통창 너머 한강, 교량, 산 능선, N서울타워·롯데월드타워를 단순화한 스카이라인을 자체 제작 파노라마로 표현합니다. 실제 위치를 그대로 재현한 지리 모델은 아닙니다.
- **낮 / 밤**: 왼쪽 작업실 패널에서 전환합니다. 낮에는 햇살과 밝은 강물이, 밤에는 달·도시의 창문 불빛·교량 조명·강물 반사와 따뜻한 실내등이 나타납니다.
- **작업실 가구**: 원목 바닥, 이젤, 창가 작업 테이블, 붓과 물감 병, 책장, 벤치, 화분, 펜던트 조명.
- **캔버스 크기**: 정사각형 2048×2048, 가로형 2560×1440, 세로형 1440×2560, 작은 정사각형 1024×1024. 크기 변경 시 그림과 Undo/Redo 데이터를 같은 배율로 중앙에 맞춥니다. 비율이 다른 크기로 여러 번 바꾸면 그림이 더 작아질 수 있습니다. 새 비율의 가장자리까지 늘이거나 잘라내지는 않습니다.
- **크기 연동**: 3D 캔버스·액자·서명 위치·PNG 및 JSON 해상도가 선택한 크기를 따릅니다. 크기 변경 시 기존 액자는 제거되며 다시 완성하기로 부착할 수 있습니다.
- **완성하기 시퀀스 (Finish Artwork)**:
  1. 카메라 정면 줌인 및 조작 잠금.
  2. 작품 제목 및 작가 서명 입력.
  3. 캔버스 우측 하단 서명 각인 및 3D 몰딩 액자(우드/골드/블랙) 스냅 장착.
  4. 고해상도 DataURL 이미지 및 `strokesData` JSON 패키징, `localStorage` 영구 보관.

### 7. 타임랩스 리플레이 & PNG/JSON 데이터 추출
- 2D와 3D 획 모두 Undo/Redo, 초기화, 크기 변경과 타임랩스에 연결되어 있습니다. JSON에는 `tool: "volume"`, `neon`, `depth`와 경로·필압을 저장합니다. PNG는 입체 획을 정면에서 렌더링한 이미지로, 선택한 캔버스 해상도를 유지합니다. 입체 기하 정보 자체는 PNG에 포함되지 않습니다.
- 누적된 스트로크 데이터를 기반으로 첫 획부터 현재까지 실제로 붓질하듯 `requestAnimationFrame`으로 캔버스에 재현합니다.
- 데이터 추출 버튼 클릭 시 규격화된 Artwork JSON(`{ id, width, height, strokes, createdAt }`) 파일 자동 다운로드.

## 🛠️ 기술 스택

- **Core**: JavaScript (ES6+ Modules), Three.js (ESM), 데스크톱/터치 포인터 입력 (WebXR 연결은 향후 구현)
- **Controls**: Three.js OrbitControls (우클릭 회전 / 휠 줌 / 좌클릭 드로잉 격리)
- **Canvas Pipeline**: HTML5 Dual Canvas (Offscreen), CanvasTexture
- **Styling**: Vanilla CSS3, 글래스모피즘 (Glassmorphism), Noto Sans KR / Outfit
- **Build & Dev Tool**: Vite 6

## 🚀 빠른 시작 (Getting Started)

### 의존성 설치
```bash
npm ci
```

### 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 [http://localhost:3000/](http://localhost:3000/)으로 접속합니다.

```bash
npm test
```

## 개발 상태 및 제한

현재 실행 진입점은 `src/main.js`이며, 연결되지 않았던 초기 씬·입력·WebXR·히스토리 구현은 제거했습니다. WebXR/VR 진입 버튼과 컨트롤러 드로잉은 아직 지원하지 않습니다.

작품 저장은 브라우저 `localStorage`를 사용합니다. 이미지와 획 데이터가 저장 용량을 초과하면 영구 저장이 실패할 수 있으므로 중요한 작품은 PNG/JSON으로 다운로드하세요. 서버 저장과 가져오기 기능은 향후 개발 대상입니다.

### 화실 이동 · 미술용품실 · 장바구니
왼쪽 벽의 문을 선택해 열고 옆 미술용품실로 걸어갈 수 있습니다. 원목 진열장에는 캔버스, 수채화 종이, 붓, 튜브 물감, 연필, 목탄을 예시 용품으로 배치했습니다. **화실 둘러보기**로 이동 모드를 시작하거나 **미술용품실** 버튼으로 진열장 앞으로 바로 이동합니다.

- 그리기 화면에서도 WASD / 방향키를 누르면 현재 시선을 유지하며 화실 이동 모드로 바로 전환합니다. 입력창·상품창·작품 완성 중에는 이동하지 않습니다. 이동 모드에서 WASD / 방향키 / 화면 화살표를 누르면 이동하고, 마우스나 터치로 화면을 드래그하면 시선이 회전합니다.
- 물건에 마우스를 올리면 상품명, 가격 준비 안내와 담기 버튼이 있는 말풍선이 표시됩니다.
- 물건 또는 이름표 클릭 / E키로 상품을 살펴봅니다. 조사 시 `space-inspect`의 `detail`에 상품 정보가 전달됩니다.
- **Shift**는 장바구니를 열고 닫습니다. **조작 방법** 버튼에서 전체 안내를 확인합니다.
- 장바구니는 수량 변경·삭제와 브라우저 로컬 저장을 지원합니다. 실제 결제나 화방넷 장바구니 연동은 제공하지 않습니다.
- **이젤로 돌아가 그리기** / 이동 모드의 Esc로 기존 브러시 작업에 복귀합니다. 창이 열려 있으면 Esc는 창만 닫습니다.

진열 용품은 예시이며 현재 실제 가격·외부 구매 링크는 보류 중입니다. 실제 주문이나 결제는 진행되지 않습니다.

### Vercel 배포 · 발표용 공유 링크
`vercel.json`은 Vite 앱을 `npm run build:demo`로 빌드하고 `dist`를 배포하도록 설정합니다. 앱과 소개 자료, 오프라인 발표 파일을 함께 제공합니다.

1. Vercel에 GitHub 계정으로 로그인합니다.
2. Add New → Project에서 `Min8309/ateliera`를 Import합니다.
3. Framework Preset **Vite**, Root Directory **저장소 루트**, Production Branch **main**으로 Deploy합니다. 빌드 설정은 `vercel.json`에 포함되어 있습니다.

배포 후 접속 경로:
- `/`: 3D 화실 앱
- `/presentation/index.html`: 컨셉과 핵심 기능 소개
- `/presentation/Ateliera-overview.pptx`: 발표 자료
- `/ateliera-demo.html`: 외부 JS·이미지·폰트 다운로드 없이 실행 가능한 단일 HTML 앱. 다운로드 후 최신 Chrome/Edge에서 직접 열어 오프라인 시연할 수 있습니다.

`main`에 수정사항을 올리면 Vercel이 최신 소스를 다시 빌드합니다. 공유 링크는 인터넷이 필요하며, 발표자는 서버 관리 화면에 접속하지 않고 링크만 열면 됩니다. 로컬 HTML 실행은 해당 기기의 브라우저 정책과 WebGL 지원에 따라 제한될 수 있습니다. 저장 데이터는 브라우저·실행 주소별로 분리됩니다.

로컬 확인:
```bash
npm ci
npm run build:demo
npm run preview -- --host 0.0.0.0
```
오프라인 배포본을 별도로 갱신하려면 `npm run build:demo` 후 `deploy/ateliera-demo.html`도 소스와 함께 저장합니다. Vercel은 빌드 시 최신 파일을 생성합니다.

독립 HTML 소개 자료는 PPT 파일도 포함하여 상대 경로 없이 다운로드할 수 있습니다. 채팅 미리보기의 다운로드 제한이 있으면 소개 자료 하단의 **PPT 직접 다운로드** 또는 GitHub 파일 다운로드를 사용하세요.

### 확대·스크롤 작업 화면과 10장 작품 보관대
- 그리기 화면을 메뉴·팔레트·오른쪽 보관함과 별도의 영역으로 배치했습니다. 작은 화면에서는 작업실 설정과 보관함을 버튼으로 열고 닫습니다.
- 확대 버튼/슬라이더로 100~400% 클로즈업합니다. **휠은 위아래 이동**, **Ctrl/⌘+휠은 확대·축소**이며, 위아래 슬라이더로 터치에서도 이동합니다. **전체 보기**로 정면 화면을 복원합니다.
- 오른쪽 벽에 세로 건조대와 10단 원목 서랍을 배치했습니다. 저장된 작품의 그림·제목·날짜 라벨이 연결됩니다.
- **현재 그림 보관**은 현재 붓질 데이터를 IndexedDB에 저장합니다. 완성 작품도 동일한 보관함에 저장하며, 기존 완성작 기록은 첫 실행에 최대 10장 가져옵니다.
- 제목과 그림 날짜를 수정하고, **다시 그리기**로 2D/3D 붓질·네온·캔버스 크기를 복원합니다. 같은 작품의 재저장은 같은 칸을 갱신하며, 10장이 차면 먼저 삭제해야 새 그림을 보관할 수 있습니다.
- 날짜 기본값은 서울 시간입니다. 저장은 브라우저·접속 주소별로 유지되며, 브라우저 데이터를 삭제하면 작품도 삭제됩니다. 중요한 작품은 JSON 내보내기로 별도 백업하세요.

모든 브러시와 지우개의 크기는 최대 **500px**까지 선택할 수 있습니다. 필압과 재료별 팁 형태에 따라 실제 찍히는 폭은 달라집니다.

### 전체 화면 공간과 숨긴 이동 바
방 공간은 화면 전체를 채우며 상단 이동·확대 바는 표시하지 않습니다. WASD/방향키로 이동, Shift로 장바구니, **M**으로 미술용품실, **H**로 조작 안내, **G**로 보관함을 엽니다. 그리기 화면에서는 **Z/X** 확대·축소, **R** 전체 보기, 휠 위아래 이동, Ctrl/⌘+휠 확대·축소를 사용합니다. 창작 화면의 캔버스는 좌우 메뉴와 하단 팔레트 사이에 맞춰 배치되고 방 배경은 화면 끝까지 렌더링됩니다.

### 터치 화면 조작
터치 화면에서는 하단 **이동/그리기**, **용품실**, **장바구니**, **조작** 버튼을 사용합니다. 이동 모드에서 왼쪽 조이스틱으로 움직이고 화면을 드래그해 시선을 돌립니다. 물건은 터치로 상세를 열고 담으며, 이젤을 터치하면 그리기로 복귀합니다. 그리기 모드에서는 한 손가락은 붓질, 두 손가락은 확대·축소와 위아래 이동입니다. 손을 떼거나 창을 열거나 화면이 비활성화되면 이동이 멈춥니다.

오른쪽 작품 목록은 기본적으로 숨기고, 책장 옆 3D 보관대의 캔버스에 실제 저장 그림과 날짜를 표시합니다. 작품 캔버스를 클릭/터치하면 미리보기에서 이전 그림·제목·날짜를 확인하고 **이 그림으로 다시 그리기**를 선택할 수 있습니다. 빈칸이나 보관대·보관함 버튼은 저장/제목·날짜 수정/삭제 관리 화면을 엽니다.

### 아지 · 화실의 검정 포메라니안
블랙·그레이 털과 주둥이, 흰 발끝·금색 이름표를 가진 3D 포메라니안 **아지**가 화실을 돌아다닙니다. 아지나 밥그릇을 클릭/터치하거나 **아지 돌보기** 버튼으로 밥 주기·쓰다듬기·놀아주기·잠 재우기/깨우기를 합니다. 포만감·기분·에너지에 따라 배고픔, 행복, 졸림을 표현하고 꼬리·걸음·먹기·잠자기 애니메이션을 재생합니다. 상태는 브라우저에 저장되며, 닫혀 있던 동안의 상태 변화는 최대 8시간까지만 반영합니다. 죽음이나 강제 결제 같은 페널티는 없습니다.

아지는 기존 크기의 50%이며, 둥근 얼굴·풍성한 목털·말린 꼬리를 가진 부드러운 봉제인형 형태로 표현합니다. 흰색 털은 네 발끝에만 배치합니다. 포만감 25% 미만이면 짖으며 빈 밥그릇을 입으로 물고 캔버스 옆으로 가져와 앞발을 들며 밥을 요구합니다. 밥을 주면 그 자리에서 먹고, 잠들면 요구를 멈춥니다. 짖는 소리는 클릭·터치·키 입력 후 활성화되는 작은 합성 효과음입니다.

작품 보관대는 오른쪽 벽면에 붙이고 입구를 실내 방향으로 돌려 한강 창문 앞을 비웠습니다. 보관대의 실제 3D 크기로 이동 충돌 영역을 생성합니다.

### 모바일 브러시 메뉴
모바일 하단에는 높이 약 58px의 브러시 버튼 한 줄만 표시하며, 좌우로 밀어 모든 도구를 고를 수 있습니다. 브러시를 누르면 색상 팔레트·직접 색상 선택·크기(최대 500px)·농담·3D 돌출 설정과 실행 취소/다시 실행 패널이 열립니다. **완료** 또는 캔버스 터치로 닫습니다. 같은 브러시를 다시 눌러도 설정한 크기는 유지합니다. 설정 패널을 열고 닫을 때 남은 화면에 맞춰 캔버스 위치를 조정합니다.

한 손가락은 그리기, 두 손가락은 확대·위아래 이동으로 사용하며 그리는 도중 시점이 회전하지 않습니다. 카메라는 바닥보다 0.35 이상 높은 위치를 유지하고, 캔버스를 확대하거나 아래로 이동한 상태에서도 바닥 아래로 회전할 수 없습니다.
